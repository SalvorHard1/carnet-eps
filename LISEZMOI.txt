CARNET EPS S-A — copie de l'application (v0.94.0)
=================================================

Lancer l'appli :
  - Sur ordinateur, depuis la clé : double-clic sur « Lancer Carnet EPS S-A.bat »
    (s'ouvre dans Microsoft Edge ; sans rien installer et sans internet).
  - Sur tablette / téléphone (ou ordinateur) : https://salvorhard1.github.io/carnet-eps/
    puis « Ajouter à l'écran d'accueil » / « Installer » : l'appli marche ensuite sans internet.

Premier lancement :
  - choisis ta discipline (EPS ou SVT) et, si tu veux, ton établissement ;
  - en EPS, une « classe exemple » (3e Exemple, élèves inventés) est proposée : elle montre
    un carnet rempli (appel, leçons, évaluations, observations, appréciations, agenda).
    On la supprime d'un clic avec le bandeau en haut de la classe ;
    on peut la recréer avec « + Nouvelle classe » > « 🎓 Classe exemple ».

Ce que contient l'appli (onglets en haut) :
  Élèves    : fiches, PAI / BEP / dispenses, photos (trombinoscope PDF), import École Directe / Pronote
  Appel     : la présence du jour, rangée dans la leçon du jour
  Notes     : évaluations, degrés de compétences, fiche élève, ⇅ Excel,
              ✍ Appréciations proposées par l'appli (relues par une vérification grammaticale
              faite sur l'appareil ; tu peux toujours les modifier)
  Leçons    : données relevées à chaque leçon, observations, ⇅ Excel
  Outils    : chronos, équipes, tirage, tournoi, tableau blanc, vidéo-delay, natation, ASNS…
              (🎓 mode élève : la tablette ne donne accès qu'aux outils choisis)
  Agenda    : programmation de l'année, séquences, emploi du temps (PDF École Directe)
  Barèmes   : bibliothèque de barèmes par activité
  ⚙ Réglages du carnet (en bas de la liste des classes) : apparence, notes, compétences,
    appréciations, onglets, verrouillage automatique, partage des réglages avec un collègue.

Le principe : chaque appareil garde sa propre copie du carnet ; la clé fait passer le carnet
de l'un à l'autre. Tout se fait avec le bouton 🔑 en haut de l'appli :
  ⬇ En arrivant sur un appareil : « Récupérer depuis la clé »
  ⬆ En partant                  : « Enregistrer sur la clé » (automatique sur ordinateur)
Rien n'est écrasé : les modifications des appareils sont réunies.
Le guide complet : bouton 🔑 > « Comment ça marche ? »

Tes données :
  - le carnet chiffré est dans : Claude\carnet-eps.json (ne pas le renommer ni le déplacer)
  - les copies datées sont dans : Claude\Sauvegardes\
  - même mot de passe sur tous les appareils ; s'il est perdu, le carnet est illisible.
  - tout reste sur tes appareils : l'appli n'envoie rien sur internet.
  - 🔒 l'écran se verrouille après quelques minutes sans activité (réglable) ;
    on le déverrouille avec le mot de passe du carnet.

Attention sur un PC qui n'est pas le tien (salle des profs…) :
  l'appli garde aussi une copie des données dans le navigateur de ce PC.
  Avant de partir : enregistre sur la clé, puis efface les données du site
  (Edge > Paramètres > Cookies et autorisations de site > localhost:8080 > Effacer les données).

Si l'appli ne se lance pas : certains PC (établissement) bloquent PowerShell.
  Dans ce cas, utilise l'adresse internet ci-dessus.

Mettre à jour : le numéro de version en haut à gauche devient orange quand une nouvelle
version est prête ; touche-le pour recharger.
